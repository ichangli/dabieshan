# 数据与依赖

## 项目数据

17 个 GeoJSON 文件来自本项目 GeoServer 导出，每个包含一个 MultiPolygon，声明 EPSG:4326，并包含森林、水、气候、湿地和矿产属性。发布不代表已经核实这些指标的原始出处、统计年份或跨行政级别可比性。重新用于研究或正式成果前应补充来源与口径。

土地利用展示瓦片由 scripts/export-tiles.mjs 从 tif:cutting 导出，采用 Web Mercator XYZ 行列号，0–10 级，共 306 张。它们是渲染图片，不等同于原始分类栅格；本仓库未提供原始 TIFF 或完整 GeoServer 工作区配置。

## 地图与依赖

- ArcGIS Maps SDK for JavaScript：版本由 package-lock.json 固定。public/assets 为 SDK 运行资源，保留 Esri 版权说明；许可见 arcgis-LICENSE.md，第三方声明见 arcgis-third-party-notices.txt。
- 高德标准底图：端点参考 https://lbs.amap.com/demo/javascript-api-v2/example/thirdlayer/functile ，保留高德署名；仅按当前视图请求，不进行底图离线打包。显示时近似校正 GCJ-02 到原项目 WGS84 网格，不改变原始业务数据。
- Vue、Vue Router、Vite、TypeScript、qrcode、html2pdf.js 等依赖的版本与许可证见各自 npm 包。npm ci 按 lockfile 安装。

仓库不包含真实账号数据库、私密环境文件或作者的地图 API Key。
