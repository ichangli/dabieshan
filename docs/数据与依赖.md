## 项目数据

17 个 GeoJSON 文件来自本项目 GeoServer 导出，每个包含一个 MultiPolygon，声明 EPSG:4326，并包含森林、水、气候、湿地和矿产属性。发布不代表已经核实这些指标的原始出处、统计年份或跨行政级别可比性。重新用于研究或正式成果前应补充来源与口径。

土地利用展示瓦片由 scripts/export-tiles.mjs 从 tif:cutting 导出，采用 Web Mercator XYZ 行列号，0–10 级，共 306 张。它们是渲染图片，不等同于原始分类栅格；本仓库未提供原始 TIFF 或完整 GeoServer 工作区配置。

## 地图与依赖

- ArcGIS Maps SDK for JavaScript：版本由 `package-lock.json` 固定。`public/assets` 为 SDK 运行资源，保留 Esri 版权说明；许可见 [arcgis-LICENSE.md](arcgis-LICENSE.md)，第三方声明见 [arcgis-third-party-notices.txt](arcgis-third-party-notices.txt)。
- Esri 地形底图：默认在线加载 [World Topographic Map](https://server.arcgisonline.com/ArcGIS/rest/services/World_Topo_Map/MapServer)。应用和 README 截图保留 Esri 及数据提供方署名；署名方式参见 [Esri 官方说明](https://support.esri.com/en-us/knowledge-base/what-is-the-correct-way-to-cite-an-arcgis-online-basema-000012040)，使用范围还需遵守 [Esri 许可协议](https://www.esri.com/content/dam/esrisites/en-us/media/legal/ma-full/ma-full.pdf)及对应服务的条款。
- 高德标准底图：端点参考[官方自定义瓦片示例](https://lbs.amap.com/demo/javascript-api-v2/example/thirdlayer/functile)，保留高德署名。实现按视图请求瓦片，使用最多 64 项的内存缓存，并通过逐像素映射近似适配 GCJ-02 底图与 WGS84 业务数据的显示。底图瓦片未作为本地静态资源打包。
- Vue、Vue Router、Vite、TypeScript、qrcode、html2pdf.js 等依赖的版本与许可证见各自 npm 包。npm ci 按 lockfile 安装。
